# 🎓 Portfolio EPHEC – Mode d'emploi

## Structure
```
portfolio/
├── index.html       ← Page d'accueil (projet professionnel)
├── cv.html          ← Page CV
├── portfolio.html   ← Page avec tableau des activités + modals
├── preuves/         ← Crée ce dossier et mets tes photos/certificats dedans
│   ├── activite1-preuve.jpg
│   └── ...
└── README.md
```

## ✅ Ce que tu dois remplir

### index.html
- [ ] Ton prénom/nom partout
- [ ] Ta photo (`<img src="photo.jpg">` dans le bloc hero-photo)
- [ ] Ta description personnelle
- [ ] Ton projet professionnel (3 paragraphes)
- [ ] Tes 4 points forts et 4 axes d'amélioration

### cv.html
- [ ] Tes coordonnées (email, téléphone, ville, LinkedIn, GitHub)
- [ ] Tes compétences techniques réelles
- [ ] Ta formation (CESS + EPHEC)
- [ ] Ton stage (dates, poste, entreprise, missions)
- [ ] Tes projets académiques

### portfolio.html
- [ ] Remplacer les 6 lignes du tableau avec tes vrais thèmes/activités/heures
- [ ] Dans chaque modal (popup) : rédiger les 3 sections (cadre, apprentissages, lien projet pro)
- [ ] Dans chaque modal : décommenter la ligne `<img>` et mettre ta vraie image de preuve

## 🚀 Mettre en ligne sur GitHub Pages

1. Va sur **github.com** → **New repository** → nom : `portfolio` → **Public** → Create
2. Clique **Add file → Upload files** → glisse tout le dossier
3. **Settings → Pages → Source : main / root → Save**
4. Ton site sera sur : `https://TONPSEUDO.github.io/portfolio/`

⏱ Attends 1–2 minutes après l'upload pour que le site soit actif.
